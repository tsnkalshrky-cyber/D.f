# **App Name**: Daftar Pro

## Core Features:

- Secure User Dashboard: Robust user authentication (password-based, with support for WebAuthn/passkeys where available) and a personalized dashboard displaying key financial metrics and account overviews.
- Flexible Account Management: Ability to create, view, edit, and categorize (customers, suppliers, general) financial accounts. Includes a 'live search' functionality to quickly find accounts by name.
- Multi-Currency Transaction Logging: Record debit ('عليه') and credit ('له') transactions with automatic date entry and manual calendar adjustment. Supports multiple currencies (Yemeni Rial, Saudi Riyal, US Dollar) and includes quick-add buttons for common amounts.
- Transaction History & Archiving: Detailed transaction history view for each account, with a 'one-click settlement' feature to zero out and archive old, completed transactions.
- Smart Reminder Tool: An AI-powered tool to generate customizable reminder messages (suitable for WhatsApp or SMS) for overdue balances, based on account data and transaction specifics.
- Comprehensive Reporting: Generate visual charts to display debt movement and currency distribution. Produce professional PDF account statements complete with business name and logo, suitable for sharing.
- Cloud Data Sync & Security: Securely back up and restore application data to a cloud storage provider (e.g., integrated cloud storage or user's linked account). Implement app-level security via password or biometric authentication.

## Style Guidelines:

- Light color scheme. Primary UI elements, headers, and core components will use a professional blue: #5E9BCD.
- The background will be a very light, subtle bluish-grey for a clean look: #F5F8FB.
- Actions and highlights will use a vibrant gold/orange accent: #FFB600.
- Amounts owed 'له' (receivable) will be clearly indicated with a standard financial green: #339933.
- Amounts owed 'عليه' (payable) will be highlighted with a distinct financial red: #DF2626.
- All text will use 'Inter' (sans-serif) for its modern, clear, and highly readable qualities, suitable for both headlines and detailed financial data. It is well-suited for diverse content and adapts well to various font sizes for accessibility.
- Use clear, intuitive icons that enhance navigation and comprehension of financial actions, account types, and reporting features. Emphasize universal recognition over decorative complexity.
- Implement a clear and organized layout with full support for Right-to-Left (RTL) languages like Arabic, ensuring proper text alignment, element positioning, and navigation flow. A persistent bottom navigation bar will facilitate quick switching between main sections.
- Incorporate subtle and swift UI transitions and feedback animations, ensuring a professional and responsive feel without distracting from financial data. Emphasis on utility and predictability.
